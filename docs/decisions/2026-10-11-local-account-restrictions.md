# Scoped synthetic account restrictions

Date: 2026-10-11. **AUTHORIZED — build-feature delegation**, actual user request
"ok lets do it and spawn agents what you need to spawn" and Agent 3 dispatch
under the canonical four-feature wave. No separate human blueprint approval.

Only owner tooling provisions local fixture targets and exact admin-to-target
grants; support capability/assignment never grants account authority. Runtime
lists only current authorized summaries and changes existing user_access status
through a fixed-search-path, capability-checking database function, with no
blanket status UPDATE. Self/admin targets are excluded, including multi-role
admins. Target revisions serialize status changes; replay UUID/payload identity
prevents duplicate history. Function rechecks current session/account/admin and
exact grant after target locks. Owner revocation shares target-first locking.
Already authorized in-flight work may finish; revocations committed before the
final check deny. History and owner capability events are append-only.

Reasons are local_access_test/local_review_test for suspension and
local_restore_test for restoration. They mean fictional exercises, never legal
or misconduct findings. No sensitive free-text notes, contacts, learner data,
bookings or notification content appear in this feature.

Sessions stay stored. Existing Learli guards deny restricted requests and the
existing provider session-create hook refuses new sign-in. This is not provider-
wide logout. Restore changes only access, subject to all other current permission,
tutor review, guardian and booking expiry rules. No roles/review/link/booking
mutation, refund, email or deletion follows either action. Historical already
disclosed content cannot be retracted by an access-state change.

Alternatives rejected: blanket runtime status updates, support-case-derived
authority and a searchable all-account queue. Rollback disables the surface and
preserves data. Real safety/appeals/incident ownership, retention, consent,
safeguarding, commercial and production policies remain OPEN launch gates.
