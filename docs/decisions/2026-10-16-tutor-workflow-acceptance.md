## Decision

Use the actual register → verify → Become a tutor → Start tutor application
path. No Tutor signup-selector feature is required. Profile name changes use
Account Settings; education/experience/qualifications share Teaching background.
Use broad learner levels including College Support. Photos/pricing checks are
Not Applicable while unsupported; do not add uploads, a grade engine or commerce.

Compare one authorized learner and one booking reference through Parent/Tutor
dashboards, private link coordination, assigned-Tutor completion after scheduled
end with an audit event, and history. A guardian-managed learner uses the Parent
account in this scenario. Tutor acceptance is conditional on actual implemented
policy. Do not claim a successful Parent booking where the observed journey was
blocked at Add Child. External link access, provider acceptance and actual
meeting/email receipt are distinct outcomes.

## Preserved boundaries

The completion actor was already approved separately; this decision does not
reopen or broaden it. Immutable older test policies retain their meaning.
Weekly-hour removal preserves saved bookings but is not automatically rejected
for booked hours; this checklist does not change that rule. Dated time-off
conflicts retain their existing separate guard.

The normal integration must retain guardian authority, Tutor eligibility,
current server ownership, DB overlap prevention, retry safety, private links and
minimum learner disclosure. A request for a normal interface is not permission
to relabel test capabilities as live policy or remove their security gates.

The first operating decision remains private fictional staging versus real-family
participation. Target-specific provisioning/activation, consent/screening,
confirmation/hold/change terms and account cleanup require their applicable
concrete decisions. Payments stay disabled. Approval and checklist creation are
not runtime verification or public-launch readiness; actual results belong in
the progress tracker and scoped QA evidence.
