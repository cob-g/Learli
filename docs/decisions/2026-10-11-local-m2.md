# Local-only M2 development

The repository owner requested M2 with everything local and confirmed no cloud
services, deployment or external email sends on 2026-10-11.

Use the installed PostgreSQL 17 in a repository-owned loopback cluster, with
separate development and test databases, Drizzle/node-postgres and Better Auth.
Neon remains the intended hosted PostgreSQL provider; no hosted connectivity or
TLS behavior is verified by these local checks. Runtime and migration helpers
reject remote URLs. Do not reuse the local configuration as production setup.

Capture verification/reset messages in private ignored local files; no Resend
calls. Local account creation accepts synthetic `.test` addresses only. New
accounts receive no roles; trusted local fixture tooling creates synthetic role
accounts. This does not approve minor enrollment, guardian proof, tutor eligibility,
payments, deployment or public launch. Final design gates remain unchanged.
