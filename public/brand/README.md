# Learli brand artwork

Original, unmodified SVG exports from the owner-supplied Learli brand kit 2.0,
October 2026, adopted for the UI on 2026-10-13. The source archive remains
`learli-brand-kit.zip` in the repository root. Use the primary wordmark on paper
or white, the reverse on navy, and the icon alone for application metadata.
Do not stretch, recolor, redraw, add effects, or place the icon beside the wordmark.
Photography briefs in the kit are not shipping assets.

`learli-email-wordmark.png` is a 408 × 145 PNG rasterization of the unmodified
`learli-wordmark.svg`, exported with macOS `sips` for inline email compatibility.
It is attached with a Content-ID, not downloaded from the local website. Keep
the SVG as the source of truth; this is an email-body logo, not a Gmail avatar.
